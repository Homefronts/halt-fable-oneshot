# Halt, one-shot prompt for Claude Fable

Paste [PROMPT.md](./PROMPT.md) into Claude Fable as the only instruction.

It includes the product, the military Grok-bot UI, the planner rules, the vehicle and tank checks, Apple Maps and Waze handoff, and the live data sources (EPA, auto-data.net, Nominatim, Photon, ArcGIS, Valhalla, OSRM, CARTO, xAI). No API keys are in this repo.
